# ANIKKVA — портфолио продуктового дизайнера. Спецификация

Дата: 2026-09-26
Референс по духу: combine.pics (не копия). Собственная идея — **«чернила»**.

## 1. Цели

- Личное портфолио продуктового дизайнера ANIKKVA.
- Дух Combine: моно-типографика капсом, навигация «таблетками», раскиданные карточки, переключатель Random / Grid / List, текст-манифест.
- Своё: собственный шрифт **Anikkva Ink** с чернильными затёками и сквозная тема «чернила» в анимациях.
- Контент — файлы в репозитории; позже поверх них подключается админка Keystatic без миграции.
- Языки: RU (по умолчанию) и EN.

Вне рамок сейчас: админка (только совместимая структура), блог, формы обратной связи, аналитика.

## 2. Стек

- **Next.js** (App Router, TypeScript), статическая генерация всех страниц.
- **MDX** для текстов кейсов, About, CV (`next-mdx-remote` или `@next/mdx` + frontmatter через `gray-matter`), валидация метаданных — **zod**.
- **Motion** (framer-motion) — layout-анимации, переходы страниц, появления.
- **Lenis** — плавный скролл.
- Стили — CSS Modules + CSS-переменные (без Tailwind, чтобы точно контролировать типографику).
- Хостинг позже — Vercel (бесплатно).
- Шрифт — Python-скрипт на **fontTools** + **skia-pathops** в `font-lab/`.

## 3. Маршруты

```
/                        → редирект на /ru
/[lang]                  главная
/[lang]/work/[slug]      кейс (type: case) или галерея (type: gallery)
/[lang]/about            обо мне
/[lang]/cv               резюме + скачать PDF
/[lang]/playground       эксперименты
```
`lang ∈ {ru, en}`. Проект `type: link` не имеет своей страницы — карточка открывает `externalUrl` в новой вкладке, со значком ↗.

## 4. Контент

```
content/
  site.json                  имя, роль, email, соцсети, манифест (ru/en)
  projects/<slug>/
    index.ru.mdx
    index.en.mdx
  playground/<id>.json       { media, caption: {ru,en}, year }
  about.ru.mdx / about.en.mdx   frontmatter: title, photo, skills, clients
  cv.ru.mdx / cv.en.mdx         frontmatter: title, pdf, experience, education
public/
  work/<slug>/cover.(jpg|png|svg|mp4), 01.jpg …   медиа проектов (Next раздаёт только public/)
  playground/, manifesto/, about/
  cv/anikkva-cv.pdf
```
Пути к медиа в контенте — абсолютные от `public/` (например `/work/<slug>/cover.jpg`); формат совместим с Keystatic (`image({ directory: 'public/work', publicPath: '/work' })`).

Frontmatter проекта (схема zod; неверные данные → ошибка сборки с понятным сообщением):

```yaml
title: string
type: case | gallery | link
externalUrl: url              # обязателен только для link
year: number
role: string
team: string?                 # опционально
duration: string?
tags: string[]
cover: path                   # картинка или .mp4
size: S | M | L               # размер карточки в Random (по умолчанию M)
order: number                 # порядок в Grid/List
featured: boolean             # показывать на главной
```

Если у проекта нет перевода на текущий язык — берётся RU-версия.

MDX-блоки: `<Media full />`, `<MediaGrid cols={2|3} />`, `<Video />` (автоплей без звука, в зоне видимости), `<BeforeAfter />`, `<Quote />`, `<Stats />`.

Заглушки на старте: 8 демо-проектов (5 case, 2 gallery, 1 link), 9 элементов playground, тексты About/CV/манифеста — рыба в тоне продуктового дизайнера. Обложки — сгенерированные абстрактные градиенты/формы.

## 5. Визуальная система

- Фон **#FFFFFF** (чисто белый).
- Чернила (текст) **#141726** — сине-чёрный.
- Плашка героя / подложки — светло-серый **#F2F2F2**.
- Отдельного цветного акцента нет (выбрано 2026-09-26): акцент = цвет чернил #141726; ховеры и ссылки выделяются подчёркиванием, инверсией таблеток и чернильными эффектами.
- Типографика: Anikkva Ink для всего; интерфейс — капс 11–12px с трекингом; манифест — очень крупный (clamp до ~8vw); логотип-герой — на всю ширину.
- Навигация — «таблетки» со светло-серым фоном, скругление 999px.

## 6. Главная

1. **Шапка** (sticky): `ANIKKVA` слева; справа `PROJECTS VIEW · ♺ RANDOM · ∷ GRID · ☰ LIST · ABOUT · CV · PLAY · RU/EN · GET IN TOUCH`. Переключатель видов — только на главной; на остальных — `← WORK`. На мобильном — одна таблетка `MENU` → полноэкранное меню.
2. **Герой**: `anikkva` огромным Anikkva Ink на плашке #F2F2F2, лёгкий параллакс, чернильное «проявление» при загрузке.
3. **Проекты**, вид хранится в `?view=random|grid|list` (по умолчанию random):
   - **Random** — холст на несколько экранов, карточки S/M/L в позициях из детерминированного генератора (seed), без перекрытий; при скролле — параллакс с разной скоростью. Повторный клик RANDOM — новый seed, карточки перелетают.
   - **Grid** — 3 колонки (планшет 2, мобильный 1), подпись: название · год.
   - **List** — строки: год · название · роль · теги; при ховере у курсора всплывает превью обложки.
   - Переход между видами — Motion `layout` / `layoutId`, одни и те же карточки перелетают.
   - На мобильном Random = одна колонка со случайными горизонтальными смещениями.
4. **Карточка**: картинка или видео (loop, muted, играет только в зоне видимости); на ховере — название капсом; появление через `<InkReveal>`.
5. **Манифест** из `site.json`: крупный текст с инлайн-картинками и символами (`∴ ⊗ ⇦`); слова «впитываются» по мере скролла. Кнопка `READ ABOUT ME ↗`.
6. **Футер**: email, Telegram, LinkedIn, Behance, `↑ BACK TO TOP`.

## 7. Внутренние страницы

- **Кейс**: обложка (shared-element переход с карточки), строка-паспорт `ГОД · РОЛЬ · КОМАНДА · СРОК · ТЕГИ`, MDX-тело, sticky-оглавление по H2 справа (десктоп), внизу «Следующий проект →».
- **Галерея**: короткое описание + медиа крупно подряд; тот же паспорт и «следующий проект».
- **About**: фото с чернильной проявкой, подход, скиллы/инструменты, компании.
- **CV**: опыт таблицей-списком, образование, `DOWNLOAD PDF ↓`.
- **Playground**: masonry из шотов и видео, клик — полноэкранный просмотр (Esc/стрелки).

## 8. Тема «чернила»

- Один глобальный SVG-фильтр (`feGaussianBlur` → `feColorMatrix` порог), интенсивность задаётся CSS-переменной / анимируется Motion.
- `<InkText>` — крупный заголовок, «растекается» при ховере/появлении (только для крупного кегля).
- `<InkReveal>` — появление блоков/фото как растекающейся капли (маска с тем же фильтром).
- Курсор — чернильная точка, «затекает» (увеличивается и сливается) над карточками; только при `pointer: fine`.
- `prefers-reduced-motion: reduce` → фильтры статичны, без параллакса, без Lenis, мгновенные переходы.

## 9. Шрифт Anikkva Ink

- Основа — **JetBrains Mono** (OFL), сила затёков **medium** (fill 40, spread 8, soften 8 на 1000 UPM) — выбрано по образцу 2026-09-26.
- `font-lab/build.py`: для каждого глифа находит острые внутренние углы и стыки штрихов, добавляет «затёки» (скругляющие наплывы), слегка скругляет концы; union контуров через skia-pathops; параметры (`spread`, `blob_size`, `corner_threshold`) в конфиге.
- Выход: `AnikkvaInk-Regular.woff2`, `AnikkvaInk-Bold.woff2` + `OFL.txt` с указанием основы; новое имя семейства (Reserved Font Name основы не используется).
- Готово: `public/fonts/AnikkvaInk-Regular.woff2`, `AnikkvaInk-Bold.woff2`, `OFL.txt`. Пересборка: `cd font-lab && .venv/bin/python build_final.py --base jetbrains --strength medium`.

## 10. Готовность к админке

- Контент только в `content/` и `public/`, формат совместим с Keystatic collections (папка на запись, MDX + frontmatter, медиа рядом).
- Keystatic-конфиг в этот этап не входит.
